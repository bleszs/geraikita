# Koreksi penerimaan pribadi — v0.10.0

Riwayat → Batalkan barang masuk → alasan 5–240 karakter → periksa dampak → konfirmasi. Harus milik akun aktif, bukan batch kolektif, belum dibatalkan dan stok tersedia cukup. Mengurangi stok/biaya sekali; catatan asal, alasan dan ekspor tetap ada. Tidak melakukan retur/refund eksternal. Jika respons hilang, periksa panel tindakan tertunda.

Lihat [alur penggunaan](USER_FLOWS.md), [offline](OFFLINE.md) dan [arsitektur](ARCHITECTURE.md). Data contoh versi sebelumnya hanya berada pada arsip dan fixture pengujian.
