# Arsip versi demo

Dokumen, hasil evaluasi dan README di folder ini menggambarkan versi sebelum v0.10.0. Profil, histori, harga dan skenario di dalamnya adalah fixture pengembangan. Angkanya tidak digunakan oleh aplikasi aktif dan tidak menjadi hasil penggunaan usaha nyata.

Panduan aktif berada di [README proyek](../../../README.md). Database lama tetap disimpan terpisah pada data/gerai-kita.sqlite; aplikasi memakai data/gerai-kita-live.sqlite.
