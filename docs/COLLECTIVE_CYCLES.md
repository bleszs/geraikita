# Siklus pembelian bersama — v0.10.0

Pengelola memasukkan penawaran nyata. Minimal tiga izin kebutuhan aktif dan semua persetujuan pada versi sama diperlukan untuk menyimpan rencana. Rencana membekukan alokasi; tidak langsung menambah stok. Masing-masing mencatat penerimaan fisik bertahap, ongkir dibebankan sekali. Siklus baru menjaga stok/histori, menghapus izin/persetujuan/penawaran siklus sebelumnya. Harga pemasok dan tenggat harus diisi kembali.

Lihat [alur penggunaan](USER_FLOWS.md), [offline](OFFLINE.md) dan [arsitektur](ARCHITECTURE.md). Data contoh versi sebelumnya hanya berada pada arsip dan fixture pengujian.
