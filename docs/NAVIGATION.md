# Navigasi

Ringkasan menampilkan penjualan yang benar-benar tercatat, stok perlu perhatian, dan langkah berikutnya dari kelengkapan data. Produk & stok berisi bahan, penerimaan dan resep. Catat pesanan menampilkan ekstraksi/manual beserta draft. Saran kulakan menghubungkan histori dengan izin kebutuhan. Beli bersama mengatur penawaran, persetujuan dan penerimaan. Surplus dan Riwayat memakai catatan tersimpan.

Pengaturan akun tersedia pada sidebar/Menu untuk nama usaha, kata sandi, serta pengaturan kelompok oleh pengelola. Lihat [panduan pengaturan](ACCOUNT_SETTINGS.md).

Ponsel menyediakan navigasi bawah Ringkasan, Pesanan, Stok, Bersama dan Menu. Menu membuka navigasi lengkap dan Keluar akun. Tidak ada pemilih usaha demo. Nama akun aktif tampil pada header; tombol Perbarui data mengambil perubahan anggota lain tanpa mengubah catatan.

Layar kosong menjelaskan isian pertama yang dibutuhkan. Tidak ada data pelengkap otomatis untuk mengisi tabel. Viewport desktop 1440px dan ponsel 320px diperiksa; sepuluh tes browser mencakup navigasi, formulir, akun, pembaruan dan offline. Ini simulasi Chrome desktop, bukan uji perangkat fisik.
