# Pembatalan rencana — v0.10.0

Rencana bisa dibatalkan sebelum ada penerimaan aktif. Pembatalan mengembalikan tahap persetujuan dan tidak menghapus catatan asal. Rencana yang memiliki penerimaan aktif harus dikoreksi sesuai aturan batch terlebih dahulu. Memulai siklus baru tidak otomatis memperbarui penawaran pemasok.

Lihat [alur penggunaan](USER_FLOWS.md), [offline](OFFLINE.md) dan [arsitektur](ARCHITECTURE.md). Data contoh versi sebelumnya hanya berada pada arsip dan fixture pengujian.
